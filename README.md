# 🚧 NISHANT NAHAR — DEVELOPER PORTFOLIO

> **Live, fast, and built without fluff.**

This is my personal portfolio, engineered from the ground up to be a high-density, recruiter-focused web experience. It relies on a strict **Neo-Brutalist** design system to communicate technical proficiency, aesthetics, and personality within 10 seconds of loading.

---

## 🏗 THE DESIGN SYSTEM

Most portfolios fall into two traps: they are either generic templates or chaotic animation playgrounds. This site operates on one strict design rule:

> **"Flat by default → aggressive on interaction."**

- **The Base:** Heavy 3px black borders, stark contrast, and a continuous slanted blueprint grid. Nothing moves. Nothing distracts.
- **The Interaction:** When a user hovers over a project or a skill card, it instantly snaps upward with a harsh drop shadow. Buttons plunge physically downward when clicked. The interface feels tactile, engineered, and responsive.

---

## ⚡ THE TECH STACK

> **Zero Frameworks. Zero Bloat.**

This entire application is built using:

- **HTML5:** Semantic, accessible, and structured for SEO.
- **Vanilla CSS3:** Heavy use of CSS variables for theming, complex grid architectures for mobile-to-desktop scaling, and intricate `repeating-linear-gradient` backgrounds.
- **Vanilla JavaScript:** Powers the mobile navigation, real-time scroll progress, and the dynamic project filtering system (Top 3, Web, Automation, ML).

---

## 📡 LIVE DATA INTEGRATIONS

I don't just list my skills; I prove them. The "Activity" section pulls live data directly from developer APIs to show real-time stats:

- **GitHub Activity Trends:** Fetches a dynamic, high-contrast line/area chart of my commit history using the `github-readme-activity-graph` API.
- **GitHub Contribution Calendar:** Renders my live contribution squares via `ghchart.rshah.org` in a mobile-optimized, horizontally scrollable container.
- **LeetCode Progress:** Hits `leetcode-stats-api.herokuapp.com` to dynamically render my total problems solved, difficulty breakdowns (Easy/Medium/Hard), and global ranking.

Because this relies on the pure fundamentals of the web, there is no `npm install` or build step required.

1. Clone the repo:
