# 🚧 NISHANT NAHAR — DEVELOPER PORTFOLIO

> **Live, fast, and built without fluff.**

This is my personal portfolio, engineered from the ground up to be a high-density, recruiter-focused web experience. It relies on a strict **Neo-Brutalist** design system to communicate technical proficiency, aesthetics, and personality.

---

## 🏗 THE DESIGN SYSTEM

- **The Base:** Heavy 3px black borders, stark contrast, and a continuous slanted blueprint grid.
- **The Interaction:** Tactile, engineered, and responsive interface with aggressive shadows on hover.

---

## ⚡ THE TECH STACK

- **HTML5:** Semantic and SEO-optimized.
- **Vanilla CSS3:** Custom grid architectures and Neo-Brutalist styling.
- **Vanilla JavaScript:** Powers navigation, filtering, and real-time data fetching.

---

## 📡 LIVE DATA INTEGRATIONS

The "Activity" section pulls live data directly from developer APIs:

- **GitHub Stats:** Real-time fetch of repository count and total stars, plus a live contribution calendar via `ghchart.rshah.org`.
- **LeetCode Progress:** Dynamically renders total problems solved and difficulty breakdowns (Easy/Medium/Hard).
- **Codeforces Stats:** Live rating, rank, and problem-solving breakdown.

---

## ⚙️ RUNNING LOCALLY

1. Clone the repo:
   ```bash
   git clone https://github.com/Its-Nishant-10/portfolio.git
   ```
2. Open `index.html` in your browser.
